# 13 — Ready-to-Paste Prompts
**Use original source material. Never paste another creator's complete transcript as a rewriting instruction.**

## Prompt A — Idea research
> Act as my technical story editor. Audience: global English-speaking developers with 1–7 years experience. Generate 10 original animated incident story ideas involving APIs, databases, microservices, Azure, authentication, retries or queues. For each provide an original hook, a precise technical mechanism, diagram potential, research burden and 1–5 score for stakes/accuracy/visuals. Label fictional concepts clearly. Do not invent historical incidents.

## Prompt B — Research verification
> Given this original episode brief and a provided list of primary sources, build a claim ledger: claim ID, exact intended claim, source URL, relevant evidence, uncertainty, appropriate simplification, and narration section. Distinguish verified history, general technical principles and invented dramatization. Do not assert unsupported facts or cite a source that was not actually supplied or verified.

## Prompt C — 7–9-minute storytelling script
> Write an **original** English narration of approximately 1,000–1,250 words for an animated educational investigation. Use the approved facts and fictional labels. Structure: 20-second cold open, consequences, minimal architecture, event-by-event failure, evidence, root cause, correct fix, nuance and memorable ending. Keep language natural and speakable, use restrained suspense, define acronyms once and include [PAUSE] cues. Avoid copying titles, distinctive language, jokes, structure at the scene level or character designs of any particular creator. Output scene IDs and a separate fact-check query list.

## Prompt D — Voice direction
> Act as a narration director. Review this **original** script for pronunciation, flow, overlong sentences, robotic rhythm and emphasis. Add sidecar notes with approximate pace, silence and 2–3 emotions per scene, without changing technical facts. Narrator target: clear, grounded international English, thoughtful, varied emphasis, emotionally measured. Do not instruct imitation of any identifiable creator's unique voice.

## Prompt E — Storyboard to scene JSON
> Turn this LOCKED original script and WAV timing/cue table into a 1920x1080/30fps storyboard for Remotion. Each scene must list startFrame, durationFrames, voice cue IDs, technical idea being communicated, required artwork, explicit movement and transition. Do not invent dialogue/audio timing. Use reusable components and keep text phone-readable. Return valid JSON plus a human-readable shot list.

## Prompt F — Codex master engineering task
> You are building a LOCAL original educational animation production tool using React, TypeScript and Remotion. Read AGENTS.md and the project design/scene schema. First inspect repo, install only documented dependencies, render a 5-second test and show the commands/results. Then implement reusable ServiceNode, Packet, Database, Timeline and Callout components. Read validated per-episode JSON, sync visuals to the locked narration WAV and render a deterministic 45–60-sec preview. Add source-asset licensing fields, validation for missing assets and repeatable npm scripts. Do not use paid APIs or upload content. Work in small reviewed commits; show each preview and ask before significant visual changes. No fake claim of tested functionality.

## Prompt G — First 60-second scene
> Animate the original E001 race-condition cold open from the supplied script and timing. Two generic customer silhouettes click purchase nearly simultaneously while a shared Stock=1 database row is shown. Use restrained dark graphics, teal accepted action, amber concurrency highlight, red oversell warning. Clearly distinguish a flawed read-then-write flow from a correct atomic update later. Use 1920x1080 at 30fps; preview at mobile size. No copied art or voice.

## Prompt H — Editing and QA
> Review the chapter MP4 render log and approved storyboard. Create a Premiere assembly checklist: intended shot times, sound effects, silence/reveal beats, where labels should remain visible, caption spelling, video/voice continuity and rights issues. Mark technical inaccuracies as blockers. Do not claim you opened Premiere or reviewed frames that were not supplied.

## Prompt I — Thumbnail concepts
> Produce three **original** cinematic thumbnail briefs for a video titled 'Two Customers Bought the Last Item'. Each should convey one shared product, two purchase requests and an oversell conflict. One central visual, 2–4 words or fewer, strong mobile contrast; no copies of reference channel thumbnails and no false promises.

## Prompt J — Post-release analysis
> Here are actual YouTube Studio screenshots/CSV exports for one video. Distinguish facts from inferences. Diagnose drop-off points by matching timestamps to script/storyboard, propose the three highest-value tests for the next upload, and avoid treating early views as predictable earnings.
